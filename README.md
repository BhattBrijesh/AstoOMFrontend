# AstoOMFrontend

A modern and scalable frontend web application built with **React 19** and **Vite** for an astrology services platform. This project is designed to showcase astrologer profiles, services, and provide users with a smooth browsing experience through a responsive and fast interface.

## 🚀 Features

* Built with React 19
* Powered by Vite for fast performance
* Responsive UI for mobile, tablet, and desktop
* Astrologer profile pages
* Service showcase pages
* Dynamic routing
* Reusable components
* Organized folder structure
* API integration support
* Custom theme support
* SEO friendly redirects

## 🛠️ Tech Stack

* React 19
* Vite
* JavaScript
* CSS3
* HTML5
* React Router
* Axios / Fetch API
* ESLint

## ⚙️ Installation

```bash
git clone <your-repository-url>
cd AstoOMFrontend
npm install
```

## ▶️ Run Project

### Development Mode

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```
